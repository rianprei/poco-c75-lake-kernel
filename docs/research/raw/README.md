# docs/research/raw/ — unedited AI output, not normative

These files are raw agent outputs kept for traceability. They are NOT sources:
nothing here may be cited as evidence for device behavior. Normative material
lives one level up (`docs/research/*.md`, cited by SPEC/tools/docs) or in the
canonical fact log (`docs/FACTS.md`).

Contents: superseded completion reports (`FIX*_codex_report.md`), one-off
reviews (`OPENCODE4_review_codex5.md`, `CODEX6_review_repack.md`), exploratory
notes (`OPENCODE2c_dlkm_sig_vintf.md`, `OPENCODE2d_bringup_runbook_v2.md`).

Same hygiene as the parent dir: no `/tmp/`, `/home/`, `~/`, `$HOME/`,
serials/IMEI, tokens or private keys (V33 scans this directory too).
